# Tracker REMAEDE

Application web mobile de suivi d'habitudes et de ressenti pour les clientes de l'accompagnement REMAEDE (Émilie Charles).

- `app/` : l'application déployée (GitHub Pages sert ce dossier).
- `remaede-tracker.html` : le code source unique. Après modification, lancer `python3 build.py` pour régénérer `app/index.html`.
- `app/README-deploiement.md` : guide de mise en ligne, intégration Notion, remplacement du logo, modification des habitudes.
- `habitudes-proposees-v1.md` : la liste d'habitudes et de curseurs validée.

Chaque envoi sur la branche `main` redéploie l'application automatiquement.
